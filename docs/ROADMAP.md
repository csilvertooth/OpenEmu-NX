# Future releases

OpenEmu-NX is Mac-first. Future platform work is planned for:

| Platform | Discovery scope |
| --- | --- |
| tvOS / Apple TV | Controller-first library, TV navigation, ROM import and persistent saves |
| iOS / iPadOS | Adaptive interface, Files import, touch and physical controllers |
| Windows | Native frontend, graphics/audio/controller integration, packaging and updates |
| Raspberry Pi | Linux ARM64 hardware baseline, performance, TV/controller experience |

These are planning placeholders with no committed release dates. Core availability and distribution constraints must be evaluated for each platform. Cross-platform netplay requires compatible runtime profiles and verified deterministic behavior; sharing a game title alone is not sufficient.

Upcoming Mac work includes a clearer Host/Join experience, reliable downloaded-game artwork, and explicit ROM matching and transfer status. Three- and four-player netplay requires expanded runtime and room support; current network sessions support two players. Future downloads should be available to admitted players, never spectators.

Published installers and release notes remain on the [Releases page](https://github.com/csilvertooth/OpenEmu-NX/releases). This roadmap does not announce an available build.
